# Автоматизированное тестирование интернет-магазина «Дом Диванов»

Проект содержит UI-автотесты интернет-магазина [domdivanov64.ru](https://domdivanov64.ru/), разработанные на **Playwright** и **TypeScript**. Автоматизированы проверки авторизации и основной пользовательский сценарий — от выбора дивана до заполнения параметров оформления заказа.

## Технологии

- **Playwright Test** — выполнение тестов и проверки интерфейса;
- **TypeScript** — реализация тестов и Page Object;
- **Page Object Model (POM)** — разделение сценариев и логики взаимодействия со страницами;
- **Allure Report** — формирование отчётов о результатах запусков;
- **Node.js / npm** — установка зависимостей и запуск команд.

## Тестовые сценарии

| Файл | Что проверяется |
| --- | --- |
| `login.positive.spec.ts` | Успешная авторизация с корректными учётными данными и переход в личный кабинет |
| `login.negative.spec.ts` | Негативные варианты ввода данных для авторизации |
| `criticalPath.spec.ts` | Сквозной сценарий выбора товара, работы с корзиной и перехода к оформлению заказа |

**Критический путь** включает авторизацию пользователя, выбор дивана и его характеристик (ширины и обивки), добавление в корзину, проверку количества и стоимости товара, изменение количества с пересчётом итоговой суммы, переход к оформлению заказа, выбор самовывоза и оплаты наличными.

**Фактическое оформление и отправка заказа не выполняются.** Проверки завершаются до подтверждения покупки.

Тесты помечены тегами `@smoke` и `@regression`, позволяющими запускать отдельные наборы проверок.

## Установка и настройка

Для запуска необходимы **Node.js** и **npm**.

1. Склонировать репозиторий и перейти в папку проекта:

   ```powershell
   git clone <URL_РЕПОЗИТОРИЯ>
   cd domdivanov-playwright-tests
   ```

2. Установить зависимости и браузеры Playwright:

   ```powershell
   npm ci
   npx playwright install
   ```

3. Создать в корне проекта файл `.env` по образцу `.env.example` и указать данные тестовой учётной записи:

   ```dotenv
   TEST_EMAIL=example@example.com
   TEST_PASSWORD=your_password
   ```

Файл `.env` исключён из Git и не публикуется в репозитории.

## Запуск тестов

Все тесты во всех браузерах, настроенных в `playwright.config.ts`:

```powershell
npx playwright test --workers=1
```

Только Chromium, с отображением окна браузера:

```powershell
npx playwright test --project=chromium --workers=1 --headed
```

Smoke-проверки:

```powershell
npx playwright test --grep "@smoke" --workers=1
```

Регрессионные проверки:

```powershell
npx playwright test --grep "@regression" --workers=1
```

Параметр `--workers=1` обеспечивает последовательный запуск сценариев, использующих общую тестовую учётную запись и состояние корзины.

## Отчёты

Результаты запусков передаются в **Allure Report**. Для формирования и открытия отчёта:

```powershell
npx allure generate allure-results --clean -o allure-report
npx allure open allure-report
```

Отчёт позволяет просматривать статусы тестов, шаги выполнения, ошибки и доступные диагностические вложения. Каталоги с генерируемыми результатами и отчётами исключены из Git.

## Особенности реализации

- Страницы и компоненты сайта представлены отдельными классами по шаблону **Page Object Model**.
- Для взаимодействия с элементами применяются локаторы Playwright и автоматические ожидания.
- Данные для негативных проверок авторизации вынесены отдельно от сценариев.
- Перед выполнением критического пути корзина приводится к исходному состоянию.
- Выполнение действий сопровождается логированием.
- В тестах не отправляются реальные заказы.
